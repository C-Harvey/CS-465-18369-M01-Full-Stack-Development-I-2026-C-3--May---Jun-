Architecture

This project used two ways to build the front end, traditional Express HTML pages and a single-page application.
Express HTML reloads the whole page every time you click something. The SPA only updates parts of the page using JavaScript, which makes it faster.
The backend used MongoDB because it is flexible and stores data like JSON. 
This works really nice with JavaScript and makes it easier to change data while building the app.

Functionality

JSON is just a way to store and send data. JavaScript is the programming language that runs the app.

The backend sends JSON data to the frontend, and the frontend uses it to show information on the page.

I improved the code by removing repeated parts and turning them into reusable components. This made the app easier to maintain and update. 
Especially with those really nice SPA features.

Reusable UI components save time and reduce bugs because you only change them in one place.
DRY is a rule that should be followed regardless though.

Testing

The backend uses requests like GET, POST, PUT, and DELETE to talk to the database.

Testing means checking that each request returns the right data and works correctly.

Security makes testing harder because some parts need login or permissions. So you also test that blocked users cannot access protected data.
